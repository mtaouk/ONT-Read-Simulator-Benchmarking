# ONT Read Simulator Benchmarking

This repo contains files related to our study on benchmarking ONT WGS read simulation:<br>
[Taouk ML, Ingle DJ, Wick RR (2026). Benchmarking long-read simulators against Oxford Nanopore whole-genome sequencing data. _bioRxiv_. doi:10.64898/2026.05.06.723380.](https://doi.org/10.64898/2026.05.06.723380)

Contents:
* `methods.md`: CLI commands and notes
* `results/`: contains TSV result files
* `figures.Rmd`: R Markdown file to generate figures
* `figures.html`: product of the R Markdown file
* `manuscript/`: LaTeX files for the actual paper
